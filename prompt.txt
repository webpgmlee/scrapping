- 이 프로젝트는 지정된 사이트에 접속하여 사이트별 요구사항에 맞는 데이터를 스크래핑하여,
전체 사이트에서 스크래핑한 데이터를 집계하는 프로그램을 만드는 것이다.

* 요구사항
- 사이트는 4개의 사이트로 고정하고, 각 사이트별로 '00사이트 조회시작' 이라는 버튼을 만들어
한번에 모든 사이트를 스크래핑 하지 않고, 각각 스크래핑 하여 데이터를 합쳐서 xlsx로 다운로드 받을 수 있게 한다.
- 화면 순서는 사이트별 조회 버튼 → 수집 내역 → 집계 결과 표이다.
  - 수집 내역 박스는 집계 결과 테이블 위에 두고, 조회 중 진행 로그를 표시한다.
  - 사이트별 조회는 서로 섞지 않으며, 조회가 끝나면 같은 15개 컬럼으로 합친 뒤 xlsx를 바로 내려받는다.
  - 수집은 서버에서 백그라운드로 진행하고, 화면은 진행 상태를 폴링한다.
- 사이트 리스트는 아래와 같다.
    1. 나라장터: https://www.g2b.go.kr/
    2. 토지주택공사: https://ebid.lh.or.kr/
    3. 국방부: https://www.d2b.go.kr/
    4. 도로공사: https://ebid.ex.co.kr/

- 사이트별 데이터 추출 경로(메뉴클릭을 통해 접근)
  나라장터 : 입찰 > 입찰공고 > 입찰공고목록
  토지주택공사 : 입찰 > 입찰공고 > 개찰결과조회
  국방부 : 공사 > 입찰 > 입찰결과
  도로공사 : 입찰 > 공사 > 입찰결과(공사)

- 나라장터 검색·수집 순서
  - 검색유형을 개찰결과로 설정한다.
  - 검색 상세조건을 연 뒤, 업종 > 업종코드로 아래 코드만 검색한다.
    6202 (기계설비ㆍ가스공사업), 4946 (해외건설업(전문건설업-가스시설시공업-제1종)), 0040 (전문소방시설공사업)
  - 업종은 한 번에 하나만 선택할 수 있으므로 코드별로 검색한 뒤, 입찰공고번호 기준으로 중복을 제거한다.
  - 1차: 개찰결과 목록에서 진행상황이 '개찰완료'인 공고를 모든 페이지에서 먼저 수집한다.
  - 2차: 1차에서 모은 공고를 모두 수집한 뒤에만 시작한다.
    2차-1) 입찰공고번호로 개찰결과 상세(개찰완료)를 열어 투찰 업체·금액·율을 추출한다.
    2차-2) 같은 입찰공고번호로 검색유형을 입찰공고로 바꿔 검색한 뒤 공고명을 눌러 입찰공고 상세를 연다.
  - 입찰시작/입찰종료는 입찰공고 상세의 입찰진행정보 > 입찰서제출 시작일시·종료일시를 사용한다.
  - 기초금액은 입찰공고 상세의 기초금액공개가 1건 이상일 때만 입력한다. (자료없음/0건이면 비운다)
  - 입찰공고 상세에서 목록으로 돌아갈 때는 '목록'(btnBackList)을 사용한다.

- 토지주택공사는 개찰마감일시를 현재날짜 기준으로 한달로 설정하고 검색한다.
- 국방부는 개찰일자를 최근 1개월로 선택하고 검색한다.
- 도로공사는 검색조건을 기본 값으로 하고 검색한다.

- 추출해야 하는 데이터는 다음과 같다
( '지역제한','입찰시작','입찰종료','발주처','공사명','기초금액','낙찰투찰율','당사투찰율','낙찰사정율','당사사정율','추첨번호','내 투찰가격(직접입찰)','조달가격','최저입찰가(입찰율)','비고' )

- 각 사이트별 추출데이터 매핑은 다음과 같다
컬럼 1 : '지역제한'
  - 나라장터는 입찰공고 상세 화면에서 투찰제한-일반>지역제한이 '제한' 이라고 되어있는 경우 참가가능지역을 '지역제한'
    데이터로 입력한다. 제한이 아니면 '-' 로 둔다.
  - 토지주택공사는 입찰공고 상세조회 화면에서 투찰제한 > 참가지역1,2,3,4가 있는 경우 데이터로 입력한다.
  - 국방부는 입찰공고 상세조회 화면에서 제한지역 > 지역1,2,3,4,5 가 있는 경우 데이터로 입력한다.
  - 도로공사는 - 로 표시한다.
컬럼 2 : '입찰시작'
  - 입찰시작일, 입찰개시일, 입찰게시일, 공고일자, 게시일시 우선순위로 데이터를 찾아서 입력한다.
  - 나라장터는 입찰공고 상세 입찰진행정보의 입찰서제출 시작일시를 우선 사용한다.
컬럼 3 : '입찰종료'
  - 입찰마감일, 입찰마감일시, 입찰/견적서 마감일, 견적서 마감일 우선순위로 데이터를 찾아서 입력한다.
  - 나라장터는 입찰공고 상세 입찰진행정보의 입찰서제출 종료일시를 우선 사용한다.
컬럼 4 : '발주처'
  - 공고기관, 발주기관 우선순위로 데이터를 찾아서 입력하고, 없는 경우 각 사이트명으로 대체한다.
컬럼 5 : '공사명'
  - 목록의 공고명, 공사명, 입찰건명을 우선 사용하고, 없으면 상세 화면 값을 사용한다.
컬럼 6 : '기초금액'
  - 나라장터는 입찰공고 상세 화면에서 기초금액공개가 1건 이상인 경우 기초금액을 입력한다.
  - 토지주택공사는 입찰공고 상세 화면에서 기초금액 데이터가 있는 경우 입력한다.
  - 국방부는 입찰공고 상세 화면에서 예산금액 데이터가 있는 경우 입력한다.
  - 한국도로공사는 설계금액을 기초금액으로 입력한다.
컬럼 7 : '낙찰투찰율'
  - 낙찰한 업체의 투찰율로, 투찰율 = 입찰(투찰)가격 ÷ 예정가격 × 100
컬럼 8 : '당사투찰율'
  - '필성건설 or 필성건설 주식회사'의 투찰율로, 투찰율 = 입찰(투찰)가격 ÷ 예정가격 × 100
컬럼 9 : '낙찰사정율'
  - 낙찰한 업체의 사정율로, 사정율 = 예정가격 ÷ 기초금액 × 100
컬럼 10 : '당사사정율'
  - '필성건설 or 필성건설 주식회사'의 사정율로, 사정율 = 예정가격 ÷ 기초금액 × 100
컬럼 11 : '추첨번호'
  - 비워 놓는다.
컬럼 12 : '내 투찰가격(직접입찰)'
  - '필성건설 or 필성건설 주식회사'가 입찰(투찰)에 참여했다면 투찰가격을 입력한다.
컬럼 13 : '조달가격'
  - 비워 놓는다.
컬럼 14 : '최저입찰가(입찰율)'
  - 투찰(입찰) 가격 중 최저 투찰(입찰)가를 입력한다.
컬럼 15 : '비고'
  - '필성건설 or 필성건설 주식회사'가 입찰(투찰)에 참여했다면 순위를 추출하여 입력한다. (지정된 업체의 순위 '/' 전체 입찰 참여 업체 갯수)

- 조회된 데이터에 페이지네이션(pagination)이 적용되어 있다면, 검색 조건의 페이지를 순회하여 데이터를 추출한다.
- 조회된 데이터에 원하는 데이터가 없다면 해당 항목의 <a>를 찾아서 상세화면에 접근하여 데이터를 추출한다.
- 나라장터는 진행상황 컬럼의 데이터가 '개찰완료'인 행의 버튼을 눌러서 개찰 상세화면에 접근한다.
- <a>태그로 상세화면에 접근할 수 없다면 <button>태그를 찾고 그래도 없다면 오류로 화면에 출력한다.
